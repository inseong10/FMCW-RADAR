128×128(S3a-1, 92404·92406)과 비교한다. 셀 수는 2배다.

- PL prepare는 1.110→2.259(×2.0), CFAR은 2.390→4.714(×2.0)로 셀 수에 비례했다.
- PL FFT는 1.400→9.953(×7.1)이다.
  - E14 두 번(약 2×1.4ms) 외의 약 7ms는 분할 재배치와 결합 단(Doppler 1단, 16,384 버터플라이)에서 나온다.
  - 결합 버터플라이는 셀마다 인라인되지 않는 `fft128_real/imag/pack` 호출 6회와 int64 나눗셈·나머지 4회를 쓴다(코드 확인, 별도 계측 없음).
- PS FFT(FFTW double 256×128)는 5.969→15.583(×2.6)이고, CFAR은 4.457→8.976(×2.0)이다.

## 해석

- 256×128(25.6ms)에서 PS+PL은 처리 실시간을 충족한다. 여유는 8.0ms(주기의 31%)다.
- PS-only는 처리 자체가 주기를 넘어 불합격이다. FFT만으로 주기의 61%다.
- PL 분할 경로(방법 A)는 보드 하드웨어에서 독립 기준과 전bin이 같다. 결합 단계의 Q15 floor·포화도 기준 모델과 같다.
- PL FFT의 결합 비용은 결과를 바꾸지 않고 줄일 여지가 크다(인라인 디코드, 산술 시프트 floor). 256×256 같은 다음 크기에 앞서 검토할 후보다(미측정).
