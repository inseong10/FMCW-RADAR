# Recorded 128x128 simulator input

`radarsimpy_128x128.rspb` contains input I/Q datagrams generated by Windows
RadarSimPy 15.5.0, not computed FFT outputs or simulator software. It is the exact
frame used in the Zybo experiment: one channel, 128 chirps, 128 samples per chirp,
1.6 MHz sample rate, a 30 m target moving at -10 m/s. See `input_metadata.json`.
SHA256: `aa06ff124034310216693c1398f2f1061c9a6ce32e9ea6f5687675849934c976`.

The RSPB0001 format stores big-endian packet lengths followed by original RSPY
datagrams. Replaying this fixture requires no RadarSimPy installation:

```bash
python tools/sender/replay_udp.py benchmarks/fixtures/radarsimpy_128x128.rspb --ip BOARD_IP --port 5000
```

For new input, run `tools/sender/sender.py --pulses 128 --samples 128` with your
own matching RadarSimPy installation. The sender uses seed 42, an 80 us chirp,
100 us PRP and a 24.0–24.1 GHz sweep. The committed recording, rather than a
new simulation on a different simulator version, defines this measured case.
